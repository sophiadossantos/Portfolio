# Portfólio de Sophia dos Santos

Site pessoal com estudos de caso de Product Design e UX/UI.

## Como rodar

```sh
npm install
npm run dev
```

## Comandos

- `npm run dev`: inicia o servidor de desenvolvimento
- `npm run build`: gera a versão de produção
- `npm run images`: gera as versões WebP de `src/assets` em `src/assets/optimized`
- `npm run lint`: verifica o código

## Feito com

- TanStack Start
- TypeScript
- React
- Tailwind CSS
